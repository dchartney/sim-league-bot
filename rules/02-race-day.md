# Race Day

2.1. All Races are run on iRacing.com platform.

2.2. Race information:

2.2.1. Fixed Setups (iRacing or League Provided)

2.2.2. 75% Fuel

2.2.3. Weather is set to Forecasted Weather, Auto Cloud Cover, Auto Temperature, Wind Speed Calm, Auto Wind Speed Direction.

2.2.3.1. Weather is determined by iRacing's Tempest Forecast system which accounts for when the date the race is scheduled, and historical data for weather around the Racetrack.

2.2.4. Track State:

2.2.4.1. Practice: 20%

2.2.4.2. Qualifying: Carried over from Practice

2.2.4.3. Race Start: 30%

2.2.5. Practice: 8:30 PM EST

2.2.6. Qualifying: 9:30 PM EST, 2 Laps (10 Minutes), Strict Scrutiny

2.2.7. Gridding: Approximately 9:40 PM EST

2.3. Race Length is series / track type dependent.

2.4. Hardcore Level: Clutch Assist Only

2.5. Damage: On, 1 Fast – Repair

2.6. Tires:

2.6.1. SCSRA ARCA Series: 3 Sets on Pit Road

2.6.2. SCSRA NextGen Series: 4 Sets on Pit Road

2.7. 3 Green / White / Checkered attempts. No Yellow flag after white flag is shown.

2.8. 1 Stage break

2.8.1. See 3.5.3, Caution within 5 laps of stage and 3.6.1.

2.9. ALL INCIDENTS, RULE INFRACTIONS AND PENALTIES GET REVIEWED BY THE ADMIN TEAM POST RACE, BEFORE ANY PENALTIES ARE HANDED DOWN.
