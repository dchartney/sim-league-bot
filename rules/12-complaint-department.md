# Complaint Department

12.1. If you think a driver is causing an issue on track, please send video evidence with wording of the exact issue / complaint you have with another driver to any member of the admin team. Not all problem drivers cause accidents. The admin team will review it. If the admin team feels it is a warranted reason for concern, we will notify the driver and try to resolve the issue. If the driver continues, they will receive a 1 race suspension. If it persists, they will be removed from the league at the admin team's sole discretion.

12.2. It is not likely that rules will be changed during a season, but for the benefit of the league, the league owner and admin team can and will make changes if warranted.
